## What I work on:
- ML-driven sparse-matrix vector multiplication (SpMv) which learns from sparse matrices features and dynamically selects the optimal matrix format (CSR, COO, DIA, ELL) based on FLOP/s. The matrices are from the SuiteSparse Matrix Collection. My proposed extension is on exploring permutation for rearranging the matrix allowing for hybrid format. Extension of SMAT Autotuner PLDI 2013, reimplemented in C without original source code nor AI assistance. Benchmarked at Sapienza University of Rome CS Department Cluster. (Work in progress - Advanced Architecture Course).
- Residual Number System (RNS) on ML Model Quantization, I have theoretically proved the limitation of RNS for model quantization in IEEE 754 FP32, also rediscovered potential research directions (like network parallelism for Homomorphic Encryption, and efficient inference with integers instead of floating points as some hardware use them) (Report published on Github - Independent Research as Research Assistant at Prometheus Laboratory)
- My own proposal for an improvement for Binary Splitting-Tree Slotted Aloha (BS-TSA) MAC protocol for RFID networks (Work in Progress - Autonomous Networking course)
- Bachelor thesis on Deep Learning and WiFi-Sensing for Indoor Positioning of Robots using single AP (obtained dataset state of the art), designed my own custom CNN architecture and vanilla VAEs. I also fixed a data leakage on the original paper and dataset author's training pipeline. Manuscript in preparation for publication under Prometheus Laboratory.
